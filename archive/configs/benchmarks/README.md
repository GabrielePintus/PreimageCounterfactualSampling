# Archived Benchmark Configs

This directory stores historical or superseded benchmark configs that are kept
for reference but are no longer part of the active operational surface.

Typical reasons a config ends up here:

- replaced by a cleaner or more focused successor
- tied to an older research branch
- redundant with a newer active benchmark family

Active benchmark configs live in:

- [configs/benchmarks](/home/gabrielepintus/Documents/github/PreimageCounterfactualSampling/configs/benchmarks)

Examples of archived categories here:

- old Adult-only exploratory configs
- superseded CertCF alpha ablations
- older random-anchor query-search variants that were replaced by the current
  boundary-random nearest-anchor line
